# ReneStore local setup

See the root [README](README.md) for prerequisites, environment-variable names, migration instructions, verified CSV import steps, and the two-terminal development workflow.

Do not copy credentials from old notes or commit `.env` files. Create local environment files from the checked-in `.env.example` templates and use credentials issued for your own database and integrations.

The project does not define or publish default administrator credentials. Use an authorized account configured for your environment.
